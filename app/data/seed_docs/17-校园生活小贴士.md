# 校园生活小贴士

## 一、校内停车与打车

- 校内停车按学校公布的收费标准执行，具体费用以现场公示为准。
- 打车可以让司机开进学校，下单时把定位设在宿舍楼下即可。
- 车辆进校后 15 分钟内驶出学校免收停车费。
- 进校门时需向门卫出示在校学生信息证明，如智慧交大页面或学生证。

## 二、宿舍垃圾袋

每人每月可以在宿管处领取一次垃圾袋，基本够一个月使用，在登记表自己宿舍那一栏签字即可。

## 三、宿舍热水与直饮水

宿舍楼内的热水机不需要每次开蓝牙扫码，找到绑卡机完成绑定后即可贴卡打水。绑定前请带上手机和校园卡（或其他带磁性的卡、带 NFC 功能的手机、手环、手表），按墙上张贴或显示屏提示的步骤操作。

绑卡机位置：大部分宿舍楼的绑卡机在一楼；没有的可以询问宿管。南图（南区图书馆）在 103 门口饮水机旁，北图（北区图书馆）在一楼卫生间。

绑定操作步骤：打开小程序“乐校通” → 右下角“我的” → 登录后选择“校园卡片” → 点击“扫码绑卡”。

## 四、水价与计费咨询

- 热水 0.08 元/升。
- 直饮水 0.27 元/升。
- 如认为计费有问题，可电话咨询饮水机服务商锦言行：15297919882，服务时间 8:00—18:00。
