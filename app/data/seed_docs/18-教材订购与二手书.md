# 教材订购与二手书建议

## 一、订书是否可以取消

大一下学期开始，不再强制在图书馆购买新书。班长使用的订书后台可以删除订新书的信息，这些钱可以省下来做别的用途。

## 二、怎么判断课程重要程度

打开个人培养方案，按学分从高到低排序，各门课程的重视程度就一目了然。可以向带班党员等前辈打听哪门课是开卷考试，这类课程推荐购买二手书，往往笔记更全。

## 三、可以不用买的书

1. 线性代数和概率统计的《学习指导书》：蓝色封面，与高数指导书是同一系列，实际使用率很低。
2. 形势与政策（时事报告）：一学期只有四节课，使用价值有限。
3. 就业指导、创新创业过程与方法：不排除最后一节课开卷考试，按需购买。
4. 工程训练与劳动教育：期末可在群文件找【金工实习】报告模板修改使用。建议一个班买一本书，把需要做的习题部分扫描后按需打印，不必每人一本。

## 四、英语课教材

英语课除课本外还需要使用大学体验英语（iSmart）和长篇阅读，这两项都可以直接在拼多多或淘宝购买激活码，比新书便宜。iSmart 是两学期一册，注意不要买重复。听力书按需购买，期末考试可能会从听力书中选取语段。

## 五、课本改版

课本改版影响不大，老师通常按固定课件讲课。平时分构成和划重点时注意听讲即可。
